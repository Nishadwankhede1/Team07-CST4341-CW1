# CST4341 Data Management for BI, Coursework 1 (Team07)

SQL scripts for the Mumbai taxi company database.

## SQL scripts (run in order in MySQL Workbench)

| File | Contents |
|------|----------|
| sql/01_create_tables.sql | Creates the schema: 25 tables, foreign keys, CHECK constraints and the vehicle_assignment trigger |
| sql/02_load_sample_data.sql | Inserts 2,618 sample rows into all 25 tables |
| sql/03_business_queries.sql | Stakeholder queries Q1 to Q7 |
| sql/04_integrity_tests.sql | Integrity tests T1 to T6 |

The data is sample data created for privacy. It does not contain real customer or driver details.
